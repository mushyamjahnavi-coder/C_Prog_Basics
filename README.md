# LEARNING C AND GITHUB

Tracking my learning of C through github

##  Repository Structure

* **`01-ARITHMETIC_CALC/`** - Basic math programs.
  * `calc.c`: Calculator using two numbers.
  * `area.c`: Area and Perimeter of Rectangle.
  * `cube.c`: Cube of a number
  * `avgnum.c`: Average of 3 numbers
  * `digit.c`: Checks if given number is digit(0-9) or not.
  * `smalln.c`: Smallest of 2 numbers.
  * `armstrong.c`: Checks whether a three-digit number is an Armstrong number or not
  * `naturalnum.c`: Checks if given number is Natural number or not.

##  Environment

* Compiler: GCC
* Editor: VS Code
